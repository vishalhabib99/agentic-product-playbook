On AWS: where Bedrock and SageMaker sit

    
Every pattern above runs on the same AWS building blocks. Amazon Bedrock is where you use models and managed agent parts. Amazon SageMaker AI is where you build, tune and host your own models. Switch the diagram to On AWS to see the service behind each lane and step.

    

      

        Use models · serverless API
        Amazon Bedrock
        
Foundation models (Claude, Llama, Mistral, Amazon Nova and more) behind one API, plus managed building blocks.

        
    
          
  • Converse API: model calls with tool use, streaming, prompt caching, Intelligent Prompt Routing, batch inference
    • 
          
  • Knowledge Bases: managed RAG (chunk, embed, hybrid search, rerank, GraphRAG, text-to-SQL)
    • 
          
  • Guardrails: prompt-attack, content and PII filters, contextual grounding check, Automated Reasoning checks
    • 
          
  • AgentCore: managed harness, Runtime, Gateway (tools as MCP), Identity, Memory, Policy, Code Interpreter, Browser, Observability. Bedrock Agents is now “Agents Classic”, closed to new customers
    • 
          
  • Data Automation, Nova 2 Sonic, Stability AI models: documents, speech-to-speech, image generation
    • 
          
  • Evaluations, customization: LLM-as-judge and RAG evals, fine-tuning, distillation, Custom Model Import
    • 
        

      

      

        Build and run your own models
        Amazon SageMaker AI
        
Train, fine-tune, evaluate, host and monitor models you control: open-weight, fine-tuned or fully custom.

        
    
          
  • JumpStart + endpoints: deploy open models; real-time, async and serverless inference on chosen instances
    • 
          
  • Training jobs + HyperPod: fine-tuning to large-scale training
    • 
          
  • Pipelines, Model Registry, managed MLflow: retrain-and-release loop
    • 
          
  • Ground Truth, Clarify, Model Monitor, A2I: labeling, evals, drift alerts, human review. In maintenance mode since Jul 30, 2026: existing customers only, no new features
    • 
        

      

    

    
Rule of thumb: start on Bedrock. Move one step to SageMaker AI when you need custom weights, a model Bedrock doesn't host, specific hardware or latency, or full control of serving. Small custom models (injection classifier, reranker, embeddings) are the usual first SageMaker endpoints.
