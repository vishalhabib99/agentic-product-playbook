# Contributing

This playbook gets better when people who ship AI products add what they've seen. Thanks for helping.

## What's most useful

- **A failure mode that isn't on the list.** What happened, how it was caught (or should have been), and the review question that would have caught it earlier.
- **A missing question in a template.** Something you wished you'd asked before launch.
- **A correction.** Anything outdated, unclear, or wrong.

## How to contribute

1. **Open an issue first** using one of the [issue forms](https://github.com/vishalhabib99/agentic-product-playbook/issues/new/choose). Small fixes (typos, broken links) can go straight to a pull request.
2. **Anonymize everything.** No company names, customer data, internal metrics, or anything covered by an NDA. Describe the pattern, not the incident.
3. **Match the house style:** plain words, short sentences, and a concrete example. Every rule should come with the question a PM asks in review.

## Credit

Accepted additions are credited by GitHub handle in the commit and, for new failure modes, in the file itself.
